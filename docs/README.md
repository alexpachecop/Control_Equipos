# Documentación de Control de Equipos

Índice de esta carpeta:

1. [Arquitectura](01-arquitectura.md) — stack, estructura del proyecto, cómo
   arranca, cómo se empaqueta en un `.exe`, dónde viven los datos.
2. [Pantallas](02-pantallas.md) — qué hace cada panel de la app, con
   capturas reales y enlaces a los bocetos de diseño.
3. [Base de datos](03-base-de-datos.md) — esquema de tablas y cómo
   evoluciona (migraciones inline, sin carpeta `migrations/`).
4. [API](04-api.md) — referencia de todas las rutas `/api/*`.
5. [Cómo se ha desarrollado](05-historial-desarrollo.md) — evolución del
   proyecto y resumen del trabajo más reciente.

Las capturas de pantalla en `screenshots/` están generadas con datos de
prueba (no datos reales de clientes), para poder subir esta documentación a
un repositorio sin exponer información de ningún cliente real.
